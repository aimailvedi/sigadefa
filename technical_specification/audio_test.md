# SIGADEFA
## Тест воспроизводимости акустического прототипа

Цель документа:
Подтвердить, что любой участник проекта может воспроизвести
первый звук SIGADEFA на своей системе.

---

## 1. Требования к среде

- Python 3.10+
- Установленный пакет:
  - numpy

Установка:
python -m pip install numpy

---

## 2. Команда запуска

Из корня проекта:

python src\sigadefa\audio_export.py

---

## 3. Ожидаемый результат

В корневой директории появляется файл:

sigadefa_first_sound.wav

или в архиве:

sigadefa_assets/audio/sigadefa_first_sound.wav

В консоли появляется сообщение:

Файл sigadefa_first_sound.wav создан.

---

## 4. Проверка

- Файл открывается стандартным аудиоплеером.
- Длительность: несколько секунд.
- Структура: 8 тонов.
- Источник: последовательность ATCGATCG.

---

## 5. Статус

Тест воспроизводимости: ✅ УСПЕШНО
