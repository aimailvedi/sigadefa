# SIGADEFA
## Инструкция по работе с проектом (рабочая)

Документ собирает практические инструкции, возникающие в ходе
реальной разработки проекта SIGADEFA.

---

## 1. Общий принцип работы

1. Все действия выполняются из корня проекта.
2. Изменения в коде и документации:
   - сначала создаются локально,
   - затем фиксируются через git add / git commit / git push.
3. Каждый этап должен:
   - оставлять артефакт (файл, звук, документ),
   - иметь запись в хрониках,
   - быть воспроизводимым.

---

## 2. Запуск акустического прототипа

Команда запуска:

python src\sigadefa\audio_export.py

Результат:
Создаётся файл sigadefa_first_sound.wav

## 3. Типовые проблемы и решения

### Проблема 1: ModuleNotFoundError: No module named 'numpy'

Причина:
Пакет numpy не установлен в системе.

Решение:
python -m pip install numpy

---

### Проблема 2: Ошибки кавычек в Python после вставки из PowerShell

Причина:
Использование экранированных кавычек \" внутри Here-String.

Решение:
Всегда использовать:
@' ... '@
для Python-кода.

---

### Проблема 3: Ошибка импорта FrequencyModel

Причина:
Неверный путь импорта при запуске скрипта напрямую.

Решение:
Использовать локальный импорт:
from frequency_model import FrequencyModel

при запуске из папки src/sigadefa.

---

## 4. Решение проблемных вопросов с ИИ

Все решения, найденные в диалоге с ИИ, фиксируются здесь,
чтобы:

- не повторять одни и те же ошибки;
- сохранять инженерную историю проекта;
- обучать следующих участников проекта.

Текущие зафиксированные кейсы:

1. Установка numpy.
2. Очистка синтаксиса Python после вставки из PowerShell.
3. Коррекция путей импорта.
4. Проверка реального создания WAV-файла через ls.
