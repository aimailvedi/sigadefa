# Критические правки v1.1/v1.2

Набор прототипов фиксирует последние правки для снижения рисков:

1. Строгая генерация `meaning_id`-состояний без фантомных ключей.
2. Честный blind-test UI без доступа к правильному ответу.
3. Устойчивая Fisher-Yates мешалка.
4. Единый `requestAnimationFrame` цикл для фазы «Плод».
5. Контрактная проверка целостности в PoorMode.
6. Проверка `isActive` через `FeatureRegistry` + health check.
7. Централизованный `OrganismKernel` как стаб-контракт.
8. Интегрированный протокол запуска v1.2.

> Папка содержит референсную реализацию и предназначена для интеграции в основной фронтенд-контур.
