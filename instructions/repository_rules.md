# Правила ведения репозитория SIGADEFA

## Общие принципы
- Один коммит = одна логическая операция
- Все изменения должны сопровождаться документацией
- Любой эксперимент фиксируется в хрониках

## Структура
/docs — научная документация  
/src — код  
/sigadefa_chronicles — философские и событийные записи  
/instructions — технические регламенты  

## После каждого изменения ОБЯЗАТЕЛЬНО:
git add .
git commit -m \"Смысловое описание изменения\"
git push
