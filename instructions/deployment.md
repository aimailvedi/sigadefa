# Инструкция деплоя и проверки сайта SIGADEFA

## Локальная проверка сайта
1. Установить зависимости:
   pip install mkdocs mkdocs-material

2. Запустить сервер:
   mkdocs serve

3. Открыть в браузере:
   http://127.0.0.1:8000

4. Проверить:
   - кликабельность всех разделов
   - отсутствие битых ссылок
   - корректность отображения текста

## Генерация статического сайта
mkdocs build

Результат появляется в папке /site
