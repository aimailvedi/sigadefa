# Журнал проблем и решений SIGADEFA

Этот документ фиксирует все технические ошибки,
проблемные ситуации и пути их решения,
найденные в диалоге «Человек — ИИ».

---

## Проблема №1: WAV не создавался
**Причина:** отсутствовал numpy, ошибка импортов  
**Решение:**
pip install numpy  
Исправление путей импорта  
Проверка Python 3.14

---

## Проблема №2: mkdocs-material не был установлен
**Причина:** тема указана, но пакет отсутствовал  
**Решение:**
pip install mkdocs-material

---

## Проблема №3: Битые ссылки в mkdocs.yml
**Причина:** в nav использовались пути с префиксом docs/
**Решение:** использовать относительные пути без docs/
