# Инструкции по ведению проекта SIGADEFA

Этот раздел содержит все регламенты, правила, технические инструкции и журнал
решения проблем, возникающих в ходе разработки проекта SIGADEFA.

## Структура раздела:

- deployment.md — правила публикации и деплоя сайта и репозитория
- repository_rules.md — правила ведения репозитория и структуры проекта
- problems_and_solutions.md — журнал ошибок и решений (история диалога с ИИ)
- workflow_with_ai.md — регламент взаимодействия с ИИ-ассистентом

Данный раздел является **каноническим техническим регламентом проекта**.
