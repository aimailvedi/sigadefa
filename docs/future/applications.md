# Области применения

Потенциальные области применения проекта SIGADEFA включают:

- образовательные платформы и визуализацию учебных данных;
- научно-популярные и исследовательские проекты;
- генеративное искусство и медиа-инсталляции;
- мультимодальные интерфейсы для анализа данных;
- экспериментальные системы человеко-машинного взаимодействия.

Проект ориентирован на междисциплинарное использование.
