# Вычислительное ядро

Вычислительное ядро проекта SIGADEFA реализовано в виде Python-пакета
sigadefa, центральным элементом которого является модуль requency_model.py.

Ядро выполняет следующие функции:
- приём последовательностей A, T, C, G;
- преобразование нуклеотидов в числовые значения;
- расчёт интервалов;
- масштабирование в частотный диапазон.

Ядро спроектировано как расширяемая библиотека для дальнейших модулей
акустической, визуальной и языковой интерпретации.
