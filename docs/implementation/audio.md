# Акустическая интерпретация

Акустический уровень SIGADEFA представляет собой перевод частотных значений
в слышимый диапазон и формирование звуковых структур:

- одиночные тона,
- интервалы,
- аккорды,
- ритмические последовательности.

Звук рассматривается как способ прямого восприятия генетических паттернов.
