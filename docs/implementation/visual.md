# Визуальная интерпретация

Визуальный уровень основывается на сопоставлении частотных значений
спектральным цветам и геометрическим формам.

Визуализация может включать:
- цветовые шкалы,
- динамические графики,
- абстрактные структуры.

Цель визуального уровня — сделать частотную структуру наблюдаемой.
