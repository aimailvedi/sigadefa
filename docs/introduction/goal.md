# Цель проекта

Создание единой вычислительной и смысловой системы, позволяющей:

- преобразовывать нуклеотидные последовательности в частотные модели,
- переводить частоты в акустические, визуальные и символические формы,
- формировать на этой основе язык SIGADEFA.

Конечной целью является создание живой мультимодальной платформы для исследования
и осмысления структуры ДНК.
