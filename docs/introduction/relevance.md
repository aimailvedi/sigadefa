# Актуальность проекта

Современная наука оперирует всё более точными моделями живых систем, однако язык описания
генетического кода остаётся в основном математическим и абстрактным.

Проект SIGADEFA предлагает расширить это поле восприятия за счёт перевода структуры ДНК
в чувственно воспринимаемые формы: звук, цвет, форма, символ.

Актуальность проекта заключается в создании нового интерфейса между данными и человеческим
восприятием.
