# Инструкция: деплой и запуск сайта SIGADEFA

## 1. Локальный просмотр сайта

1. Перейти в папку проекта:
   - \D:\GIT\sigadefa\

2. Убедиться, что установлены:
   - Python 3.14
   - \mkdocs\
   - \mkdocs-material\

3. Собрать и запустить сайт локально:
   - \mkdocs build\
   - \mkdocs serve\

4. Открыть в браузере:
   - \http://127.0.0.1:8000/\

## 2. Публикация на GitHub Pages

1. Внести изменения в файлы документации или кода.
2. Выполнить:
   - \git add .\
   - \git commit -m "Краткое описание изменений"\
   - \git push\

3. GitHub Actions автоматически пересобирает сайт и публикует его
   на ветку \gh-pages\.

4. Публичный адрес:
   - \https://aimailvedi.github.io/sigadefa/\

## 3. Мини-чеклист перед пушем

- Сайт локально собирается без критических ошибок: \mkdocs build\
- Нет незапланированных файлов (проверка \git status\).
- Сообщение коммита понятно и описывает суть изменений.
