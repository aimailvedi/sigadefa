# SIGADEFA

**SIGADEFA (Structure, Intervals, Genes, Audition, Deflection, Form, Application)**  
— это мультимодальный научно-художественный проект, переводящий структуру ДНК  
в частотные, акустические, визуальные и символические формы.

Проект развивается как единая система:
- вычислительная модель,
- научная теория,
- язык,
- философская хроника,
- интерактивная платформа.
