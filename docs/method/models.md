# Используемые модели

Ключевой вычислительной моделью проекта является FrequencyModel,
реализованная в ядре Python-пакета SIGADEFA.

Модель выполняет:
- преобразование нуклеотидной последовательности в числовые значения;
- вычисление относительных интервалов;
- масштабирование в заданный частотный диапазон.

Дополнительно используются вспомогательные модели для:
- визуального отображения спектров,
- символического кодирования.
