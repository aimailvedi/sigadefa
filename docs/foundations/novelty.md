# Научная новизна

Научная новизна проекта SIGADEFA заключается в следующем:

- предложен мультимодальный способ интерпретации генетического кода;
- введена модель перевода нуклеотидных последовательностей в частотные и интервальные структуры;
- объединены вычислительные методы, акустика, визуальная теория и символические системы;
- создан задел для формирования нового языка описания биологических данных.

Проект лежит на стыке науки, искусства и инженерии, формируя новую зону исследований.
