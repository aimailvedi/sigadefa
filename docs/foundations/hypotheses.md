# Принятые гипотезы

В рамках проекта SIGADEFA приняты следующие базовые гипотезы:

1. Нуклеотиды A, T, C, G могут быть интерпретированы как элементы дискретной частотной системы.
2. Относительные интервалы между ними являются более устойчивыми носителями информации, чем абсолютные значения.
3. Частотные соотношения могут быть масштабированы в слышимый диапазон без утраты пропорций.
4. Полученные частотные структуры допустимо переводить в визуальные и символические формы.
5. Мультимодальная интерпретация ДНК не подменяет биологическую науку, а создаёт дополнительный слой осмысления.
