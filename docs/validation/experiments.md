# Экспериментальные подходы

Экспериментальные исследования в рамках проекта включают:

- тестирование на искусственных последовательностях ДНК;
- сравнительный анализ различных наборов данных;
- акустическое и визуальное сопоставление результатов.

Эксперименты направлены на выявление устойчивых закономерностей
частотных и структурных преобразований.
