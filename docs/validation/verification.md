# Верификация

Верификация в проекте SIGADEFA направлена на проверку корректности
вычислительных преобразований и воспроизводимости результатов.

Основные направления верификации:
- проверка соответствия численных значений входным данным;
- контроль масштабирования частот;
- повторяемость результатов на одинаковых последовательностях.

Верификация носит математико-алгоритмический характер.
